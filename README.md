# Circle Camera (가칭)

여행 릴스에서 자주 보이는 **"화면 속 동그라미에 풍경 피사체를 맞춰 찍기"** 무드를
하나의 카메라 앱으로 만드는 프로젝트.

화면에 타겟 도형(동그라미)을 띄워두고, 사용자가 피사체를 그 안에 "딱" 맞추면
앱이 정렬 정도를 실시간으로 알려주고 **맞는 순간 자동으로 촬영**한다.

## 한 줄 컨셉

> 동그라미 안에 피사체를 가두면, 맞는 순간 알아서 찍힌다.

## 현재 상태

- 단계: **설계 (Design)** — 코드 구현 전, 기획/설계 문서 정리 단계
- 1차 타겟 플랫폼: **웹 프로토타입** (브라우저 `getUserMedia` + `canvas`)
- 향후: iOS 네이티브(SwiftUI + AVFoundation + Vision)로 확장 고려

## 핵심 차별점

기존 "구도 오버레이" 앱들은 **정적인 가이드**만 그려준다.
이 프로젝트의 차별점은:

1. **정렬 어시스트** — 피사체를 실시간 인식해 원과의 fit 점수(0~100%)를 표시
2. **자동 촬영** — 정렬이 안정적으로 유지되면 흔들림 없이 자동 셔터
3. **(향후) 스마트 검출** — 풍경 속 둥근 사물을 찾아 원을 제안/스냅
