# 로드맵 (Roadmap)

검증 우선. 가볍게 만들어 반응을 본 뒤 깊이를 더한다.

## 마일스톤

### M0 — 설계 (완료)
- [x] 아이디어 평가, 경쟁 조사
- [x] 제품/기술 설계 문서화
- [x] UI 목업(docs/mockup.html)
- [x] 플랫폼·인식 방식 결정

### M1 — 수동 오버레이 + 후보정 (React Native) ★현재
- [x] 카메라 프리뷰(후면/전면)
- [x] 드래그·핀치·핸들로 움직이는 원 1개
- [x] 그리드/비율(9:16·1:1·4:5) 토글
- [x] 수동 셔터 → 미리보기 → 저장/공유/다시찍기
- [x] 후보정 모드: 사진 불러오기 → 원 프레이밍/비네팅 → 저장/공유
- [ ] 실기기 빌드·동작 검증(아이폰/갤럭시)
- **완료 기준:** 폰에서 원 맞춰 직접 찍어 저장, 또는 사진 골라 보정해 저장 가능

### M2 — L2 정렬 가이드 (차별점)
- [ ] 피사체 실시간 인식 — vision-camera Frame Processor + 경량 ROI CV
- [ ] fit 게이지 + 방향 힌트 + 상태별 원 색(idle/near/good)
- [ ] good일 때 가벼운 햅틱/하이라이트 (촬영은 여전히 수동)
- [ ] 인식 throttle(10~15fps), 60fps 오버레이 유지
- **완료 기준:** 피사체를 원에 맞춰가는 과정을 가이드가 도와준다(셔터는 직접)

### M3 — L3 스마트 검출 (확장)
- [ ] 둥근 사물 검출(Hough 등) → 원 제안/스냅
- [ ] 도형 변형(다각형/별/하트), 다중 원
- [ ] 후보정 원본 해상도 합성, 색보정/필터

## 결정한 사항

- 플랫폼: **React Native (Expo) + vision-camera** — iOS·Android 공용, 실시간 프레임 처리 강점
- 인식: **원 주변 ROI 블롭(범용 피사체)**, L2에서 적용
- 촬영: **수동 셔터**(자동촬영 X), 정렬은 가이드용 시각 피드백
- 시작 범위: 설계 문서 → 목업 → M1 구현

## 리스크 메모

- 기능이 얇아 복제되기 쉬움 → **자동 매칭 UX의 완성도**가 방어선
- 리텐션 약함 → 템플릿/챌린지/공유 루프로 "다시 열 이유" 설계 필요
- 단품 카메라 앱 수익화 난이도 → 프리미엄(도형팩/AI보정) 구조 사전 고려
